🦥 Notice Sloth

Paste a week of university notices. An open-weight model (Gemma) reads them, and you only see what you actually have to do.

Up to 8 notices per run. Text is processed by Gemma on Cloudflare Workers AI and not stored. For zero-upload, run it locally with Ollama (see the repo).

Stays in your browser between visits.

Download calendar (.ics)
Model: @cf/google/gemma-4-26b-a4b-it on Workers AI · same code runs offline on gemma4:e2b via Ollama · source (MIT). The model only reads; which bucket a notice lands in, the dates and the calendar are decided by plain code.
